# Таймер Pomodoro

## Возможности

- настройка рабочих интервалов и перерывов;
- запуск, пауза, сброс и переход к следующему интервалу;
- уведомления после завершения интервала;
- простая статистика в `localStorage`;
- музыка из MP3-файла в папке `music`.

## Запуск

```bash
npm install
npm start
```

Если Electron не установлен, страницу можно открыть напрямую через `index.html`, но системные уведомления будут работать через возможности браузера.

## Android APK

Android-версия лежит в папке `android-native`.
При сборке APK скрипт берет первый MP3 из папки `music` и добавляет его внутрь приложения как `Музыка`.

Сборка APK:

```powershell
.\build-android-apk.ps1
```

Готовый файл появится здесь:

```text
android-native\build\pomodoro-student.apk
```
